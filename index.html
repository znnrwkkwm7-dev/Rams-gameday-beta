About this app

Rams GameDay v1.9.4 beta. Scores and game data are pulled from public football data when available. v1.9.4 labels the schedule as viewer-local time and tightens/lowers the bottom navigation for better iPhone proportions. v1.9.2 names the actual cornerback matchup in the Week 1 scouting brief instead of using a generic CB2 label. v1.9.1 makes this build share-ready: kickoff times automatically follow each viewer’s local time zone, viewing guidance is no longer tied to one household, Rams Media is labeled for any fan, and the More tab includes one-tap sharing. v1.9 adds automatic venue-local game-time weather and docks the bottom navigation to the screen edge in Safari/GitHub-hosted mode. v1.8 adds opponent-aware Rams Media shortcuts. v1.7 adds Game-Week Intelligence, injury-status change tracking and a live Matchup Key Tracker that grades the weekly scouting plan as the game unfolds. The 2026 schedule, TV networks, venues and jersey selections remain saved locally as a fallback.
